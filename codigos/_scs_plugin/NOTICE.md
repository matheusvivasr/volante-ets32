# Aviso de terceiro — SCS Telemetry SDK

Este diretório contém o **SDK de telemetria da SCS Software** (fabricante do
Euro Truck Simulator 2 e American Truck Simulator), versão `1.12.1`,
vendorizado aqui só para permitir compilar o plugin que expõe a telemetria do
jogo (velocidade, RPM, luzes etc.) para o firmware do painel.

**Isso não é código do autor deste repositório** e **não está coberto pela
[`LICENSE`](../../LICENSE) MIT** do projeto. Nenhum arquivo de licença veio
junto com o download original do SDK — a ausência de um `LICENSE`/`EULA`
aqui **não** significa domínio público; por padrão, os direitos permanecem da
SCS Software.

Antes de redistribuir este repositório publicamente (fork, clone, release),
confira os termos atuais do SDK diretamente com a SCS Software — página de
desenvolvedor / fórum oficial do jogo — em vez de assumir que a
redistribuição é livre só porque nenhum arquivo de licença foi encontrado
aqui.

Fonte: `release_v_1_12_1.zip` (SCS Software).
